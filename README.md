# ARCHIVED — migrated to nixconf

This repo's Neovim config has been migrated into [nixconf](https://github.com/monk3yd/nixconf) as a Den dendritic aspect at `modules/core/nvim/`.

**What changed:**
- nixCats → [nix-wrapper-modules](https://github.com/BirdeeHub/nix-wrapper-modules) (nixCats is deprecated)
- lazy.nvim → [lz.n](https://github.com/lumen-oss/lz.n) (purpose-built for nix-managed plugins)
- All 58 plugins, LSP configs, and custom tooling ported

**This repo is read-only.** See nixconf for the current configuration.
